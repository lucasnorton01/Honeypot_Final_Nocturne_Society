Antes de empezar

Vas a procesar a mano 20 eventos reales que registró el honeypot Cowrie durante la validación del 30/09/2026, como lo haría un analista con el log crudo y sin herramientas de automatización. Antes hay 2 eventos de práctica que no se cuentan. Calculá unos 30 a 40 minutos.

  1. Tocá Mostrar evento: desde ese momento corre el tiempo.
  2. Paso 1 · Triaje y extracción. Leé el JSON, elegí el tipo de evento, decidí si es relevante y copiá los campos que tenga (sesión, IP de origen, usuario, contraseña, comando). Dejá vacío lo que el evento no trae. Tocá Campos listos.
  3. Paso 2 · Clasificación y documentación. Asigná una severidad y registrá el indicador (IoC) que corresponda, o «ninguno». Tocá Guardar y seguir.
  4. Entre un evento y otro podés descansar: el tiempo solo corre con el evento a la vista.

Hacelo solo/a, sin mirar la pantalla de otro participante y sin comentar los eventos hasta que todos terminen. Esta página es solo para P18.

No consultes servicios externos de geolocalización ni de reputación: todas las IP son direcciones internas del laboratorio. Trabajá a tu ritmo normal; no es una prueba de velocidad. No se guarda tu nombre: usá el código que te dio el equipo.

Qué poner en cada campo

CampoQué vaEjemplo
Sesiónel valor de session89d78abf875c
IP de origenel valor de src_ip172.19.0.7
Usuario / Contraseñalos valores de username y passwordadmin / test123
Comandoel texto que trae input (no la palabra «input»)uname -a
Valor del IoCel dato del indicador, no la severidad172.19.0.7 · admin:test123 · wget http://…

Si el evento no trae un campo, dejalo vacío. Podés copiar y pegar del JSON.

Criterio común para el paso 2

Tipo de evento¿Relevante?SeveridadIoC
session.connectSíBajaIP → valor de src_ip
login.failedSíBajaCredencial → usuario:contraseña
login.successSíAltaCredencial → usuario:contraseña
command.inputSíAlta si el comando contiene wget, curl, bash, sh, python, chmod, nc, tftp o /bin; si no, MediaComando sospechoso → el comando, si contiene alguna de esas palabras; si no, Ninguno
el resto (client.version, client.kex, session.params, log.closed, session.closed)NoBajaNinguno

Si el mensaje trae un hash SHA-256, el IoC es Hash. Si en algún caso no estás de acuerdo con el criterio, seguí tu juicio y explicalo en la nota.
